# Identity Basics

## What is Identity and Access Management (IAM)?

Identity and Access Management (IAM) is the practice of ensuring the right people have the right access to the right resources at the right time.

IAM includes:

- Authentication
- Authorization
- User Lifecycle Management
- Single Sign-On (SSO)
- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Identity Governance

---

## Authentication

Authentication answers the question:

"Who are you?"

Examples:

- Password
- MFA
- Smart Card
- Fingerprint

---

## Authorization

Authorization answers the question:

"What are you allowed to access?"

Examples:

- File shares
- Email
- Applications
- VPN
- Databases

---

## Active Directory

Active Directory is Microsoft's directory service that stores users, computers, groups, and security information for an organization.

It is commonly used as the source of identity for enterprise environments.
