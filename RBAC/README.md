# Role-Based Access Control (RBAC)

## What is RBAC?

Role-Based Access Control (RBAC) is a security model that grants permissions based on a user's role rather than assigning permissions directly to individual users.

This simplifies administration, improves security, and supports the principle of least privilege.

---

## Example

Departments:

- HR
- Finance
- IT

Groups:

- HR_Employees
- Finance_Employees
- IT_Employees

Users are added to groups, and the groups receive permissions.

---

## Benefits

- Easier administration
- Consistent permissions
- Better security
- Faster onboarding
- Faster offboarding
- Supports compliance and auditing
