# Identity Lifecycle Management (JML)

## What is JML?

Identity Lifecycle Management ensures user access is managed throughout employment.

The three phases are:

### Joiner
A new employee joins the company.

Typical IAM tasks:

- Create user account
- Assign groups
- Provision applications
- Enable MFA
- Verify access

---

### Mover

An employee changes roles.

Typical IAM tasks:

- Remove unnecessary access
- Assign new role-based access
- Update group memberships
- Validate least privilege

---

### Leaver

An employee leaves the company.

Typical IAM tasks:

- Disable account
- Remove application access
- Remove VPN access
- Remove licenses
- Document completion
